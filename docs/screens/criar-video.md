# Tela: Criar vídeo

Acessível pelo menu lateral (**Criar vídeo**). É um assistente (wizard) de 5
passos, indicados na barra de progresso no topo da tela.

## Passo 1 — Configurar avatar

Escolha um avatar já salvo, ou clique em **"+ Configurar novo avatar"** para
treinar um novo. Ver detalhes em
[configurar-avatar.md](configurar-avatar.md). É preciso ter pelo menos um
avatar selecionado para avançar.

Neste passo também é possível definir um **cenário** e **traje padrão** (por
prompt de texto ou envio de imagem) que ficam como sugestão pré-preenchida no
passo 3.

## Passo 2 — Roteiro

Escreva o roteiro no campo principal — é exatamente o texto que o avatar vai
"falar" no vídeo, palavra por palavra.

Se preferir, descreva o vídeo em uma frase no campo **"Gerar com IA"** e clique
em **"Gerar com IA"**: o roteiro é rascunhado automaticamente e preenche o
campo principal (ainda editável depois).

É preciso ter algum texto no roteiro para avançar.

## Passo 3 — Recursos (Escolha os recursos para este vídeo)

Confirma ou troca, só para este vídeo, o avatar, o cenário e o traje. Os
campos já vêm preenchidos com os valores padrão definidos no passo 1, mas
podem ser sobrescritos aqui sem afetar o avatar salvo.

## Passo 4 — Duração

Escolha a duração do vídeo: **15s**, **30s** ou **60s**.

## Passo 5 — Gerar e revisar

Clique em **"Gerar vídeo"**. O vídeo entra em processamento — o status muda de
*na fila* → *processando* → *pronto* (ou *erro*), com uma barra de progresso
que é atualizada automaticamente a cada poucos segundos. Quando o status fica
*pronto*, o player exibe o vídeo e há um botão para baixá-lo.

O vídeo gerado também aparece na aba **Conteúdo → Biblioteca de vídeos**,
mesmo depois de sair desta tela.
